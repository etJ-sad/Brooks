# Запуск Brooks на AURORA (Фаза 0)

Цель: на экране AURORA в 4K виден лог загрузки с картой памяти и списком PCI-устройств,
и внизу зелёная строка `NPU FOUND: Arrow Lake NPU ... 8086:ad1d`.

Займёт минут 15. Нужно: USB-SSD (всё на нём будет стёрто в варианте А), телефон для фото экрана.

## 1. Ключ BitLocker (обязательно, до всего остального)

Смена настроек Secure Boot может заставить Windows спросить ключ восстановления BitLocker.
Без ключа доступ к диску с Windows будет потерян.

1. Запусти **Terminal (Администратор)** и выполни:
   ```
   manage-bde -protectors -get C:
   ```
   Найди блок **Numerical Password**: 48 цифр в группах по 6. Сфотографируй или перепиши на бумагу.
   Тот же ключ лежит на https://account.microsoft.com/devices/recoverykey. Проверь, что он там есть и совпадает.
2. Приостанови BitLocker на 3 перезагрузки, чтобы смена Secure Boot не вызвала запрос ключа:
   ```
   manage-bde -protectors -disable C: -RebootCount 3
   ```
   Через 3 загрузки Windows защита включится сама.

Если `manage-bde` пишет, что шифрование выключено, этот шаг можно пропустить.

## 2. Получить образ

Вариант 1 (без сборки): GitHub → репозиторий → **Actions** → последний зелёный запуск **build** →
внизу артефакт **boot-image** → скачать и распаковать. Внутри `brooks.img` и `brooks-esp.zip`.

Вариант 2: собрать самому в Ubuntu или WSL2 (`make img esp`, см. README).

## 3. Записать на USB-SSD

### Вариант А: весь диск под Brooks (проще всего)

1. Скачай **Rufus** (https://rufus.ie).
2. Подключи USB-SSD. Если Rufus его не видит: раскрой **Показать расширенные свойства диска** и
   включи **Показывать внешние USB-диски** (USB-SSD Rufus по умолчанию прячет).
3. **Устройство**: проверь по размеру и имени, что выбран именно USB-SSD, а не диск AURORA.
4. **Метод загрузки** → ВЫБРАТЬ → `brooks.img`. Нажми **СТАРТ**. Если спросит режим, выбери **DD**.
5. Rufus предупредит, что всё на диске будет уничтожено. Подтверди.

Образ занимает 64 МиБ, остальное место на SSD останется неразмеченным. Если Windows потом предложит
«исправить» или «отформатировать» диск, откажись.

### Вариант Б: сохранить место под Ubuntu на том же SSD (как в плане, шаг 4)

1. **Управление дисками** (Win+X → Управление дисками) → USB-SSD → удалить разделы (данные пропадут) →
   **Создать простой том** 512 МБ, файловая система **FAT32**, метка `BROOKS`.
   Остальное место оставь пустым под Ubuntu.
2. Распакуй `brooks-esp.zip` в корень этого раздела. Должно получиться:
   ```
   X:\EFI\BOOT\BOOTX64.EFI
   X:\boot\limine\limine.conf
   X:\boot\kernel.elf
   ```

## 4. Настройки UEFI на AURORA

1. Выключи AURORA полностью (Пуск → Завершение работы, с зажатым Shift, чтобы не было «быстрого запуска»).
2. Включи и сразу жми клавишу входа в BIOS (обычно **F2** или **Del**; на некоторых моделях **Esc** → меню).
3. **Security → Secure Boot → Disabled.** (Limine и ядро не подписаны.)
4. Убедись, что загрузка с USB разрешена (**USB Boot: Enabled**). «Fast Boot», если есть, лучше выключить на время теста,
   иначе USB может не опрашиваться.
5. Сохрани (**F10**) и выйди.

## 5. Загрузка

1. Подключи USB-SSD (лучше в порт USB-A или USB-C напрямую, без хаба).
2. Включи и вызови меню загрузки (обычно **F12** или **F11**/**Esc**). Выбери USB-SSD
   (в списке он будет как `UEFI: <имя диска>`).
3. Появится меню Limine (3 секунды):

| Пункт | Когда выбирать |
| --- | --- |
| `Brooks` | по умолчанию, режим экрана как отдала прошивка |
| `Brooks (force 3840x2160)` | если в строке `GOP:` разрешение меньше 3840x2160 |
| `Brooks (large text)` | если текст мелкий: шрифт 16x32 с увеличением x2 |

Стрелками выбрать, Enter запустить.

## 6. Что должно быть на экране

```
Brooks 0.0.1   Phase 0 boot log   build <коммит>
Boot:  Limine 9.x, firmware UEFI x64, cmdline "font=auto scale=1"
CPU:   Intel(R) Core(TM) Ultra 9 285HX
GOP:   3840x2160 32bpp ...; console 240x67 font 16x32 x1
HHDM:  ...   ACPI RSDP: ...   Serial COM1: not present
== Memory map (merged) ==        | == PCI devices ... ==
<диапазоны памяти, внизу итог RAM usable>   | 00:00.0 8086:.... Host bridge   Intel
                                 | ...
                                 | 00:0b.0 8086:ad1d 120000 Processing accelerator  Intel  <== NPU
NPU FOUND: Arrow Lake NPU (NPU37xx) at 00:0b.0, id 8086:ad1d rev .., subsystem ....
  BAR0 MMIO 0x... 64-bit
  BAR4 MMIO 0x... 64-bit
Phase 0 gate: PASS (GOP log + memory map + PCI list + NPU)
ACPI:  rev 2 OEM '...', NN tables: FACP APIC ...
IRQ:   LAPIC 0xfee00000, 1 IOAPIC, ...; TSC .... MHz (CPUID 15h); timer 100 Hz
Input: i8042 found ...
FS:    RAM file system, 9 entries from initrd
Enter: файловый менеджер (сам запустится через 15 с)
```

Сфотографируй этот экран до нажатия Enter. Потом откроется файловый менеджер (клавиши в README, справка на `1`).
Проверь, что работают стрелки, Enter, Tab и цифры. Лог загрузки можно потом листать в менеджере клавишей `2`.

`Serial COM1: not present` на ноутбуке это нормально.

**Сфотографируй весь экран** (желательно в нескольких кадрах, чтобы читались адреса) и пришли в тред:
по этим данным (BAR NPU, список устройств, карта памяти) будет строиться Фаза 1 и драйвер NPU.

Ядро ничего не пишет на диски, NVMe с Windows не трогается; файлы менеджера живут в RAM.
Выключение: в менеджере `0` → `P` (ACPI), или зажать кнопку питания на 5 секунд.

## 7. Если что-то пошло не так

| Что видно | Что делать |
| --- | --- |
| USB-SSD нет в меню загрузки | проверь, что Secure Boot выключен и USB Boot включён; попробуй другой порт; в варианте Б проверь, что раздел FAT32 и путь `\EFI\BOOT\BOOTX64.EFI` |
| Красный экран `KERNEL PANIC` | сфотографируй его целиком, это главная отладочная информация |
| Чёрный экран после меню Limine | подожди 10 с; затем выбери пункт `force 3840x2160` или `large text`; сообщи, на каком пункте висит |
| NPU не найден (жёлтая строка) | сфотографируй список PCI: возможно, NPU выключен в BIOS (ищи пункт вроде `NPU`, `VPU`, `AI Boost`) или у него другой ID |
| Мелкий текст | пункт `large text` или правка `cmdline:` в `\boot\limine\limine.conf` (например `font=16x32 scale=2`) |
| Проверить экран паники | добавь `test=panic` в `cmdline:` |
| Менеджер открылся, но клавиши не работают | сфотографируй строку `Input:` в логе. Встроенная клавиатура ноутбука обычно сидит на i8042; внешняя USB-клавиатура работает, только если в BIOS включена USB Legacy Support |
| Клавиши F1..F10 не реагируют | используй цифры 1..0 (или Fn+F) |

## 8. Назад в Windows

Выключи AURORA, отключи USB-SSD, включи. Если всё же спросит ключ BitLocker, введи 48 цифр из шага 1.
Secure Boot можно оставить выключенным до конца экспериментов или включить обратно; после включения
Windows может один раз спросить ключ, если BitLocker уже не приостановлен.
